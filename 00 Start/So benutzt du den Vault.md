# So benutzt du den Vault

- **Startseite:** [[Start]]. Von dort führt jeder Link weiter.
- **Projekte als Tabelle:** [[Projekte.base]] zeigt alle Projekt-Notizen mit Status.
- **Eigene Notizen:** einfach anlegen. Vorlagen liegen in `Vorlagen` (Strg+P → „Vorlage einfügen“).
- **Ändern erlaubt:** Alle Notizen gehören dir. Das tägliche Update legt nur fehlende Notizen neu an und schreibt nur [[TikTok – Überblick]] neu (wegen der Zahlen). Wenn du dort selbst schreiben willst, setz `manuell: true` in den Kopf.
- **TikTok im Detail:** liegt im eigenen Vault `tiktok-vault`. Hier steht nur die Kurzfassung.
- **Bilder:** landen automatisch in `Bilder`.

> [!warning] Was hier nie reinkommt
> Passwörter, Tokens, Schlüssel, Bank- oder Kontonummern, Kontostände. Wohnort nie in öffentliche Texte übernehmen.
